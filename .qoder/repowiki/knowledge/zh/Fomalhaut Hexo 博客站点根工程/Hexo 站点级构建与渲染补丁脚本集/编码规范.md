- 每个脚本顶部用多行注释写明「症状 → 根因 → 修法」三段式说明，并标注卸载方式（删除本文件或撤掉配置即回滚）。
- HTML 修补类脚本采用「渲染期 `after_render:html` 主修 + `before_exit`/`before_deploy` 兜底扫描 `public/`」的双通道模式，确保 hexo server 与静态产物都生效。
- 前端注入类脚本通过 `hexo.extend.injector.register('body_end', SCRIPT_TEMPLATE, 'default')` 注入内联 `<script id="...">`，并用 `window.__xxx` 标志位防止重复执行。
- 站点绝对地址改写一律基于 `hexo.config.url` 解析 origin/prefix，仅匹配目标 class 或 DOM 块内的链接，避免误改 canonical、og:url、CDN 等其它绝对地址。
- 脚本通过 `hexo.log.info` / `hexo.log.warn` 输出带前缀的日志，便于区分不同补丁的运行轨迹。
