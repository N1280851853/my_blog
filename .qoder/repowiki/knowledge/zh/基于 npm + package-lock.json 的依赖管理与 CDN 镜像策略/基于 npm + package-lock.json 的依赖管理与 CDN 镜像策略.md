## 1. 使用的系统/方案

仓库采用 **npm** 作为包管理器，通过根目录 `package.json` 声明运行时与构建期依赖，并通过 `package-lock.json`（lockfileVersion: 2）锁定完整依赖树。主题子目录 `themes/fomalhaut/package.json` 仅声明主题自身对 Hexo 渲染器的最小依赖，站点级依赖集中在根工程。

此外，前端第三方库（jQuery、Algolia、Twikoo、MathJax、Fancybox、APlayer、FontAwesome 等）以 **CDN 静态文件** 形式直接引用，统一指向 `https://registry.npmmirror.com/<pkg>/<ver>/files/...` 路径，由 `_config.fomalhaut.yml` 中的 `cdn:` 配置项集中管理版本与 URL。

## 2. 关键文件

- `package.json`：站点级依赖声明、`hexo.version` 约束、`engines.node >= 18`、构建脚本（`build` / `deploy:vercel` / `server`）。
- `package-lock.json`：npm v2 lockfile，记录所有依赖的精确版本、resolved URL（均指向 `registry.npmmirror.com`）与 integrity。
- `themes/fomalhaut/package.json`：主题自身的元数据与极小依赖集（`hexo-renderer-stylus`、`hexo-renderer-pug`），并声明 GitHub 仓库地址。
- `.github/dependabot.yml`：启用 Dependabot，按 `daily` 频率扫描根目录 `/` 下的 npm 依赖，PR 上限 20。
- `_config.fomalhaut.yml`：集中定义所有前端第三方库的 CDN 地址（`algolia_search_v4`、`twikoo`、`mathjax`、`lazyload`、`fancybox_v4`、`fontawesomeV6`、`aplayer_js/css`、`jquery` 等）。

## 3. 架构与约定

- **双轨依赖来源**：Node 侧构建/Hexo 插件走 npm；浏览器侧第三方 JS/CSS 走 npmmirror CDN，避免在 `node_modules` 中重复打包。
- **版本范围策略**：`package.json` 中绝大多数依赖使用 `^` 语义化版本范围（如 `hexo ^6.2.0`、`gulp ^4.0.2`），但个别包使用固定版本（如 `hexo-baidu-url-submit 0.0.6`），由 `package-lock.json` 固化实际安装版本。
- **引擎约束**：`engines.node >= 18` 强制 Node.js 环境；`hexo.version: 6.3.0` 通过 hexo 字段声明期望的 Hexo 主版本。
- **CDN 镜像集中化**：所有第三方前端资源 URL 统一以 `https://registry.npmmirror.com/...` 开头，便于切换镜像源或升级版本时只改一处配置。
- **预连接优化**：`_config.fomalhaut.yml` 显式注入 `<link rel="preconnect" href="https://registry.npmmirror.com">`，加速字体与 CSS 加载。
- **主题与站点解耦**：主题包 `themes/fomalhaut/package.json` 不继承站点依赖，仅声明渲染器依赖；站点通过 Hexo 机制将主题作为本地目录加载。

## 4. 约定与约束

- **规则（由工具强制执行）**：
  - `package-lock.json` 存在且为 npm lockfile v2，CI/协作环境应通过 `npm ci` 安装以保证可复现构建（lockfile 本身即约束）。
  - `.github/dependabot.yml` 规定对根目录 `/` 下 npm 依赖每日自动检查，最多打开 20 个 PR。
  - `package.json` 的 `engines.node >= 18` 会被 npm 在安装时校验。
  - 前端第三方库的版本与 URL 必须通过 `_config.fomalhaut.yml` 的 `cdn:` 段维护，而非散落在模板 pug 文件中。

- **观察到的约定（非强制）**：
  - 所有 npm 依赖在 `package.json` 中使用 `^` 范围（除少数固定版本包），具体版本由 `package-lock.json` 锁定。
  - 所有 CDN 链接统一指向 `registry.npmmirror.com`，未出现其他 CDN 供应商。
  - 主题包 `themes/fomalhaut/package.json` 保持最小依赖，仅声明 `hexo-renderer-stylus` 与 `hexo-renderer-pug`。
  - 无私有 registry、`.npmrc`、`GOPRIVATE`、vendor 目录等配置——依赖全部来自公开 npm 与 npmmirror CDN。
  - 无 `pnpm-lock.yaml`、`yarn.lock` 或 `go.mod`，项目完全基于 npm。
