- Markdown 博文统一以 YAML front-matter 声明 title/categories/tags/cover/description/comments/abbrlink/date 等字段，便于主题渲染与归档。
- 站点级增强代码与主题代码分离：自定义 CSS/JS 放在 `source/css` 与 `source/js`，主题升级不丢失。
- 侧栏 widget 通过 `_data/widget.yml` 的 class_name/id_name/html 结构声明，并由 `aside-calendar.js` 的 `layoutCards()` 统一保证 DOM 顺序，避免 pjax 换页时的排序错乱。
- 动态加载的 JS/CSS 文件 URL 附带 `?v=YYYYMMDD` 版本号，用于强制浏览器刷新缓存。
- 需要跨生命周期（解析期、DOMContentLoaded、pjax:complete）调用的初始化逻辑集中在 `js/modules/` 下的模块文件中，并通过全局对象（如 `window.fomalAsideCalendar`）暴露 API。
