以后新增/替换歌曲的步骤清单（要求四.3）
放音频：把 .mp3/.m4a 丢进 source/life/music/audio/（封面丢进 source/life/music/cover/，可选歌词 .lrc 丢进 audio/）。
改一处配置：编辑 source/life/music/playlist.json 的 songs 数组——新增就加一条 {name, artist, url, cover, lrc}，删除就删一条。url/cover/lrc 用站内绝对路径 /life/music/...；cover/lrc 可省略。
重新构建：npm run build（部署则再走你的 deploy 流程）。本地预览 npm run server 会监听 source 自动生效，但新增静态文件后建议重启 server 以确保被识别。
不需要动 music-local.js、index.md 或任何其它代码。
